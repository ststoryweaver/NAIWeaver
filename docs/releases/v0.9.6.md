## v0.9.6 — Persistent Cascade Previews, Safer Editing & Linux Flatpak

### New
- **Optional persistent Cascade previews on native platforms.** Enable the setting to restore each beat's last generated image and generation metadata when reopening a story. It is off by default; web hides the option because browser persistence is not supported.
- **Cascade director keyboard navigation.** Tab / Shift+Tab cycle tag suggestions and Enter inserts the highlighted suggestion. With no suggestions, Tab still moves focus.
- **Linux Flatpak downloads for EN, JA, and ZH.** These accompany the existing AppImages. Flatpak support is experimental, is not listed on Flathub, and has not been verified on Steam Deck hardware. See the [Linux installation guide](https://github.com/ststoryweaver/NAIWeaver/blob/v0.9.6/docs/linux.md).

### Fixes
- **Generation results stay with their original story and beat.** Switching stories, exiting/re-entering playback, removing a beat, or reordering beats cannot redirect an old completion into another preview. Navigating during generation preserves the user's selected beat.
- **Correct metadata throughout save and export.** Each completed render retains its own prompt, seed, and saved filename even if another beat is selected while saving/exporting. The viewed beat's save tracking is preserved.
- **Safer preview storage.** Stable IDs, hashed storage keys, atomic image/metadata records, independent corrupt-record handling, and legacy migration protect restored previews. Queued writes and late loads retain their original ownership; re-enabling persistence preserves existing images.
- **Pinch gestures do not paint accidentally.** Canvas and mask editors discard partial strokes when a second finger arrives and do not resume drawing with a trailing finger. Mouse painting still works.
- **Mobile sheets remain reachable.** Character, interaction, reference, and vibe editors account for the keyboard and safe area; scrollable sheets and flexible titles improve small-screen access.
- **Consistent saved-character insertion.** Keyboard and mouse insertion honor the same outfit-state option.
- **Bounded desktop shutdown.** Close events share one operation, preview writes get a chance to finish, and stalled calls have timeouts. Windows hides the window promptly while closing.
- **V5 auto-`teXt:` collection.** Quoted text in base and character prompts is collected at the end of the base caption, after style suffixes. Manual `Text:` / `teXt:` blocks still disable automatic collection.
- **Linux runtime packaging.** Builds bundle ONNX Runtime 1.22.0 CPU, preserve versioned libraries/symlinks, and check runtime relocation before packaging.

### Downloads

| Platform | English | Japanese | Chinese |
|---|---|---|---|
| Windows | `NAIWeaver.zip` | `NAIWeaver-ja.zip` | `NAIWeaver-zh.zip` |
| Android | `NAIWeaver.apk` | `NAIWeaver-ja.apk` | `NAIWeaver-zh.apk` |
| Linux AppImage | `NAIWeaver-x86_64.AppImage` | `NAIWeaver-ja-x86_64.AppImage` | `NAIWeaver-zh-x86_64.AppImage` |
| Linux Flatpak | `NAIWeaver-x86_64.flatpak` | `NAIWeaver-ja-x86_64.flatpak` | `NAIWeaver-zh-x86_64.flatpak` |

For Flatpak, install the downloaded file with `flatpak install --user ./NAIWeaver-x86_64.flatpak`, then launch with `flatpak run dev.naiweaver.app//experimental`. The [guide](https://github.com/ststoryweaver/NAIWeaver/blob/v0.9.6/docs/linux.md#experimental-flatpak) covers runtime setup, storage permissions, and the separate Flatpak data directory. Newer bundles must be installed manually; there is no Flatpak update repository.
