# 0.9.6 release candidate

Status: the confirmed Cascade ownership, web-setting availability, Cascade metadata, and paint/pinch blockers are fixed and covered by permanent regressions. The candidate is ready for review and commit. Publication still needs final platform-artifact checks below.

`pubspec.yaml` is set to `0.9.6+23`. Release CI is pinned to the locally validated Flutter 3.38.6 SDK, checks the tag against the source version, and runs tests/analysis before building. Publication requires all native builds, Flatpak library/startup checks, and web deployment to succeed. Pushing `v0.9.6` triggers that pipeline and publication using the [checked-in release notes](v0.9.6.md).

## Verified

- Full Flutter suite on the current fixes: **786 passed, 1 live API test skipped**.
- `flutter analyze --no-pub`: **no issues found**.
- Targeted Cascade, Canvas paint, and mask regression group: **24 passed**.
- Current English Windows release build: **passed**; executable FileVersion/ProductVersion both report `0.9.6+23` using build overrides.
- Current JavaScript web release build: **passed**; `version.json` reports `0.9.6` / `23`. The optional WebAssembly dry run reports dependency incompatibilities; the published JavaScript target compiled successfully.
- Current Chrome preview-persistence settings tests: **2 passed**, covering both saved preference values. Local CanvasKit assets were temporarily served to work around the installed Flutter SDK's Windows test-server path handling; they were removed after the run.
- Linux packaging static checks: all five shell scripts pass `bash -n`, the Flatpak JSON manifest parses, and `git diff --check` is clean. Native Linux/Flatpak execution has not been verified on this Windows host.
- The real Cascade save/export regression uses generated image fixtures, a fake API transport, and disposable local files. It verifies that navigation cannot replace the render's metadata/export filename or alter the viewed beat's save tracking.
- Session switching, exit/re-entry, removed/reordered beats, unmounted playback, failed generation, native persistence settings, preview-store migration, and pointer cancellation are covered by the permanent tests.

The tests do not issue paid generation requests. The earlier Android audit build predates the last two fixes and is not proof of the final candidate. Windows, web and Chrome checks above were repeated after those fixes. Linux runtime packaging, experimental Flatpak CI/scripts, and the Linux setup guide are included in the candidate; native Linux build/runtime validation remains pending.

## Known limitations

- [SAM 2.1 tensor mismatch (#1)](https://github.com/ststoryweaver/NAIWeaver/issues/1) is a known legacy limitation accepted for 0.9.6, not a release blocker. Runtime-loader packaging and the encoder/decoder input contract are separate problems; this candidate does not claim to repair that model.
- Browser persistence of Cascade previews is unsupported; its setting is hidden.
- Physical Android input, removable storage and device-specific UI behavior require device evidence. Passing widget tests does not replace those checks.
- Release downloads include experimental Flatpak bundles in EN/JA/ZH. Their automated installation/startup check does not establish Steam Deck hardware readiness; no Flathub listing or automatic Flatpak update repository is provided.
